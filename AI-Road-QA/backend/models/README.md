# Model files

- `road_hazard_training/` contains the uploaded YOLO11 road-hazard training project.
- `best.pt` is generated by running `python train_road_model.py` from the backend root.

The ZIP intentionally does not include a trained checkpoint: the uploaded training
repository contained code and results, but not the actual trained `.pt` weights.
The training script downloads the RDD2022 India subset (~527 MB), prepares the labels,
trains YOLO11n, evaluates it, and copies the resulting checkpoint to this directory.

After training, set `ML_PROVIDER=yolo` and `MODEL_PATH=models/best.pt` in `backend/app/.env`.
